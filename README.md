# BuildSync — Phase 2

Premium construction project showcase website foundation.

## Current stack
- React
- Vite
- Tailwind CSS
- React Router

## Run locally

```bash
npm install
npm run dev
```

## Phase 2 scope
- React project setup
- Routing
- Home, Projects, Project Details, About and Contact pages
- Reusable Navbar and Footer
- Initial project data structure
- Public asset folders

Three.js, Node/Express, MongoDB and DevOps tooling will be added in later phases.
